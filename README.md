# Fluxa — Diseño web · Buenos Aires

Landing page de [Fluxa](https://fluxa.com.ar), estudio de diseño web en Buenos Aires.

## Deploy

Este sitio está hosteado en **GitHub Pages**.

Para activar GitHub Pages:
1. Ir a Settings → Pages
2. Source: Deploy from branch
3. Branch: `main` / `(root)`
4. Guardar

## Estructura

```
index.html   ← toda la página (assets embebidos)
README.md
CNAME        ← dominio personalizado (editar si es necesario)
```
